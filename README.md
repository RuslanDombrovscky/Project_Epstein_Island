# Project_Epstein_Island
Что нужно реализовать на сайте
1. Список мероприятий
2. Форма регистрации
3. Ограничение по количеству мест
4. Подтверждение записи

Страницы сайта:
1. Титульная страница сайта где будут находится списки мероприятий по колледжам мгкэит
На данной странице находится сверху шапка(она присутствует на всех страницах) на которой будет находится логотип колледжа и
кнопка для входа в личный кабинет для администрации, на основной части страницы будут распологаться изображения
мероприятий с их названиями снизу при нажатии на них будет открываться следующая страница
2. Страница с описанием какого либо мероприятия
На данной странице находятся изображения мероприятия, их описание и кнопка для записи на него с количеством мест около
надписи "Записаться"
3. Страница с формой регистрации
На данной странице находится окно регистрации на мероприятие в котором будет надпись"Запись на мероприятие "название
мероприятия" ниже будет окно для заполнения ФИО, группа и в самому низу кнопка "Зарегистрироватся", при вводе не правильных
данных выходит ошибка о неверных введенных данных или их отсутствии, так же может выходить уведомление о том что кончились
места на мероприятие
4. Страница с сообщением об успешной рагистрации на мероприятие
На данной странице находится текст об успешной регистрации на мероприятие и кнопка снизу для возврата
на страницу с кружками
